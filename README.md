## 📌 Sobre o Projeto

Este repositório reúne a documentação, etapas de desenvolvimento, fichamentos e o texto completo do artigo acadêmico de revisão bibliográfica sobre os impactos do analfabetismo/baixo letramento digital na inserção e permanência no mercado de trabalho formal.

O objetivo do estudo é analisar como a falta de domínio sobre ferramentas e plataformas digitais atua como um mecanismo de exclusão sociotrabalhista e desencadeia dinâmicas de desânimo e esgotamento entre trabalhadores vulneráveis durante os processos seletivos modernos.
